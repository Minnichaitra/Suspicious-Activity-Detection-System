# Suspicious Activity Detection System

## Overview
This project is a smart surveillance system developed using YOLO for detecting suspicious activities in real-time video streams.

## Technologies Used
- Python
- YOLO
- OpenCV
- Machine Learning
- Computer Vision

## Features
- Real-time surveillance monitoring
- Suspicious activity detection
- Object detection using YOLO
- Automated alert generation
- Video frame analysis

## Model Used
YOLO (You Only Look Once)

## Project Workflow
1. Video input collection
2. Frame processing
3. Object detection using YOLO
4. Suspicious activity identification
5. Alert generation
